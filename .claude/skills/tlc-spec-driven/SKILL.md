# TLC Spec-Driven Skill

Conduz especificações verificáveis em `.specs/features/<feature>/spec.md` com critérios em EARS (`WHEN`/`WHILE`/`WHERE`/`IF...THEN`/`The ... SHALL`) e validação determinística via `scripts/validate_spec.py`.
